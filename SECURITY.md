# Security Policy

## Supported versions

Only the latest release on npm is supported with security fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, send an email to the maintainer:

- **GitHub**: [@dumbramkrishna](https://github.com/dumbramkrishna)
- Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature if you prefer.

Include:

1. A description of the vulnerability.
2. Steps to reproduce.
3. Any potential impact you can identify.

You will receive a response within **72 hours** and a fix will be coordinated with you before any public disclosure.
